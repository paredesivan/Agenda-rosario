# Empleados de Comercio Rosario — Teatro AEC

Comprobación: 18/10/2026. Fuente oficial:
https://www.aecrosario.org.ar/cultura/teatro/
Sala: Corrientes 450, Rosario. La página institucional declara que está abierta
a todo tipo de propuesta y público. Se incorporan anuncios teatrales de esa
sección, sin cursos, actividades exclusivas ni servicios gremiales.

Robots devolvió HTTP 200; las reglas generales permiten las páginas públicas.
Señales observadas: search=yes, ai-train=no, use=reference. Esta integración usa
un parser determinista para datos y referencias; no entrena modelos ni reproduce
notas, afiches o fotografías. No requiere login, credenciales ni APIs privadas.
En páginas revisadas no se encontró prohibición contractual explícita para este
uso factual acotado; no se presume licencia general. Se mantienen los controles
comunes: robots, caché, separación de consultas, límites y pausas HTTP 403/429.

Listado cada dos horas; hasta cuatro fichas por ejecución, caché por ficha de
24 h y rotación por antigüedad. Los errores no borran los datos válidos.

Cada ficha exige pertenencia a la categoría Teatro y referencias a la propia
sala. Se extraen días expresamente enumerados, no se expanden intervalos.
Si la nota omite el año, se usa el año de publicación exclusivamente para
anuncios de los siguientes 90 días del mismo año; queda registrado en
anio_contextual_publicacion. No se usa el año actual ni se supone un cambio
de año. Si falta hora se publica Horario a confirmar, sin usar la boletería.

El título se obtiene del cuerpo o de una denominación factual del espectáculo;
no se copia el titular periodístico. Los beneficios para afiliados AEC o socios
de Amecro se informan sin marcar Gratis para público general. El retiro y los
cupos se conservan en una descripción propia y se enlaza la nota oficial.

Se reemplazan duplicados de ACR de la misma sala, fecha y hora por la ficha
primaria, incluso cuando ACR publicó el mismo show con dos nombres diferentes.
La coincidencia por turno sólo se aplica a esta sala y a horas confirmadas.

La ficha revisada anuncia funciones el 23 y 24 de octubre a las 20. El nombre
factual generado es Show coreográfico de Ballroom Dance. No contiene un evento
fijo en el código: las fechas y los nombres se extraen de los anuncios actuales.
